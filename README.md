# my-skills

A curated pack of skills for AI coding agents, published to skills.sh.

## Install

```sh
npx skills add Otitodev/my-skills
```

## Contents

| Skill | Description |
|---|---|
| `aeroplane-deploy` | Deploy to a self-hosted Aeroplane server |
| `amazon-bedrock` | Bedrock models, agents, AgentCore, payments |
| `aws-billing-and-cost-management` | AWS bill, cost analysis, optimization |
| `aws-blocks` | Infrastructure-from-Code with AWS Blocks |
| `aws-cdk` | CDK authoring, bootstrap, deploy, troubleshoot |
| `aws-cloudformation` | Author, validate, deploy CloudFormation |
| `aws-compute` | EC2 instances, Auto Scaling, Systems Manager |
| `aws-containers` | ECS, Fargate, ECR |
| `aws-deployment` | CodePipeline, CodeBuild, CodeDeploy |
| `aws-messaging-and-streaming` | SQS, SNS, EventBridge, Kinesis, Flink |
| `aws-observability` | CloudWatch, X-Ray, ADOT, Application Signals |
| `aws-sdk-js-v3-usage` | AWS SDK for JavaScript v3 patterns |
| `aws-sdk-python-usage` | boto3/botocore patterns |
| `aws-sdk-swift-usage` | AWS SDK for Swift |
| `aws-serverless` | Lambda, API Gateway, Step Functions, SAM/CDK |
| `launch-with-aws` | Migrate/deploy web apps to AWS |
| `signing-in-to-aws` | Get AWS credentials via `aws login` |
